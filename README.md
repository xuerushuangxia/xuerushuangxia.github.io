# Su Zirui — Personal Academic Homepage

Live website: https://xuerushuangxia.github.io/

A bilingual personal homepage covering research interests, engineering projects,
education, internships, leadership and volunteering. The website is plain HTML,
CSS and JavaScript and is published through GitHub Pages from `main` at `/`.

## Updating the website

- Edit `index.html` to update the biography and experiences. English text and
  corresponding Chinese text (`data-zh`) are kept together.
- Edit `style.css` for the layout and `app.js` for interaction.
- Replace images and CV files in `assets/`, keeping links consistent.
- Commit and push to `main`; GitHub Pages will publish the changes.

For local preview, run `python -m http.server 8000` in this folder and open
http://localhost:8000/ . No build tools or additional packages are required.

Project descriptions distinguish ongoing work, preliminary hardware testing and
unvalidated performance from completed outcomes. Keep these distinctions when
editing. The vision demo uses public sample material; avoid uploading private
campus footage or personal data.

The academic layout was informed by the personal homepages of Jon Barron,
Jiajun Wu and Shuran Song. Text, photos and project materials relate to Su Zirui.
